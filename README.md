One funny line for make.fun's "The One-Line Laugh" bounty: "My fitness app congratulated me for walking ten thousand steps today, and eight thousand of them were just me pacing the kitchen deciding what to eat." The program writes that single sentence to `/output/entry.txt` — one sentence, 150 characters. The joke turns on an everyday truth everyone with a step counter recognises: the app celebrates every step, including the ones that never left the kitchen, and the punchline lands at the very end.

## Run it

```sh
node main.ts
```

It creates the output directory if needed, writes `/output/entry.txt` as UTF-8 (one sentence, 150 characters, no trailing newline), and reads the file back to confirm it matches the line exactly.
